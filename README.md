# SQL
# SQL Portfolio Project

## 📊 Project Overview
This project demonstrates practical SQL skills including database creation, data insertion, querying, and data analysis.  
The goal of this project is to design a structured relational database and extract meaningful insights using SQL queries.

---

## 🛠️ Tools & Technologies
- MySQL
- SQL (DDL, DML, DQL)
- Relational Database Concepts

---

## 🗂️ Project Structure

- `schemas for project.sql` → Database and table creation (DDL)
- `insertation.sql` → Data insertion (DML)
- `sample queries.sql` → Analytical and business queries (DQL)

---

## 🧱 Database Design

The project includes:
- Creation of structured tables
- Primary Keys
- Foreign Keys
- Constraints
- Relationships between tables

The schema is designed following normalization principles to reduce redundancy and maintain data integrity.

---

## 🔍 Key SQL Concepts Used

- SELECT statements
- WHERE, GROUP BY, HAVING
- ORDER BY
- JOINS (INNER JOIN, LEFT JOIN)
- Aggregate Functions (SUM, COUNT, AVG, MAX, MIN)
- Subqueries
- Window Functions
- Data Cleaning Queries
- Handling NULL values

---

## 📈 Sample Business Questions Solved

- Total sales by category
- Revenue by month
- Top performing products
- Customer purchase behavior
- Handling missing values
